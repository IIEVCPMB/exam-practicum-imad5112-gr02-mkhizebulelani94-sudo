//name of the app:

Campsite Commander

//Basic Overview of the app

this is an app that is based on storing the items on which you would need for a camping/outdoor trip. It has 4 xml, with three main screens: the main, details and splash screen. The app has two exit buttons in the start and the end of the application. It is very useful in keeping your things together and this app consists of parallel arrays and loops usedto make up this app

//how the system works
The way the app works is by using parallel loops which are the items, comments, categories and quantity of the items. We needed to initialize them to get them working in the code as you would need to do it before you even put the activity_main. You need to make sure that the UI is done properly as it will be a make or break for your project if you did not declare everything on the xmls or in the arrays itself.
